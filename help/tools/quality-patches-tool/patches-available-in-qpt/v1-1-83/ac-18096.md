# AC-18096：销售GraphQL日期字段返回错误的本地化格式

AC-18096修补程序修复了Sales GraphQL日期字段返回日期时格式与以前版本不同的问题，方法是将日期格式从斜杠分隔的`/`还原为短划线分隔的`-`。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83时，此修补程序可用。 修补程序ID为AC-18096。 请注意，此问题已在Adobe Commerce 2.4.9中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法） 2.4.9

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法）>2.4.8 &lt;=2.4.9-p1

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=zh-Hans)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

销售GraphQL日期字段返回以斜杠分隔的格式`(d/m/Y H:i:s)`的日期和时间值，而不是在Adobe Commerce 2.4.8中使用的以短划线分隔的格式`(Y-m-d H:i:s)`

<u>先决条件</u>：

- **[!UICONTROL General]** > **[!UICONTROL Locale Options]** > **[!UICONTROL Timezone]**： *欧洲/巴黎*
- **[!UICONTROL General]** > **[!UICONTROL Locale Options]** > **[!UICONTROL Locale]**： *法语（法国）*

<u>重现步骤</u>：

1. 创建订单。
1. 使用GraphQL检索订单日期详细信息：

   ```graphql
   query getOrders {
       customer {
           orders {
               items {
                   orderDateOK: created_at
                   orderDateFAIL: order_date
               }
           }
       }
   }
   ```

<u>预期的结果</u>：

- 这些字段在`Y-m-d H:i:s`中返回值，与版本2.4.8中的输出匹配。

<u>实际结果</u>：

- 这些字段在`d/m/Y H:i:s`中返回值，如`27/08/2026 14:12:55`，而不是`Y-m-d H:i:s`，如`2026-08-27 14:12:55`。
