# ACP2E-3211：并行添加到购物车请求为同一SKU创建单独的项目

ACP2E-3211修补程序修复了以下问题：在Storefront上同时向购物车中添加相同的产品会在购物车中创建同一SKU的单独项目，而不是将它们组合到单个项目中。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83时，此修补程序可用。 修补程序ID为ACP2E-3211。 请注意，此问题已在Adobe Commerce 2.4.8中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法） 2.4.5-p7

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法） 2.4.5 - 2.4.7-p10

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

将同一产品同时添加到购物车和店面，会在购物车中为同一个SKU创建单独的商品，而不是将它们组合到单个商品中。

<u>重现步骤</u>：

1. 创建新产品。
2. 创建新的客户帐户并登录。
3. 转到产品页面，打开&#x200B;**开发工具** > **网络**，然后将产品添加到购物车。
4. 复制将产品添加到购物车的curl (bash)请求。
5. 在两个控制台实例中使用复制的curl查询，以尽快触发两次。

<u>预期的结果</u>：

- 产品已添加为`qty=2`的单个购物车项目。

<u>实际结果</u>：

- 产品将作为两个单独的购物车项目添加。
