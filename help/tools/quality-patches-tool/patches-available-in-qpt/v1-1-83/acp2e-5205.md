# ACP2E-5205：大型目录导致管理员中的类别加载缓慢和超时

ACP2E-5205修补程序修复了在涉及大量类别和产品时，类别加载耗时较长或导致超时的问题。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83时，此修补程序可用。 修补程序ID为ACP2E-5205。 请注意，此问题计划在Adobe Commerce 2.4.9中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法） 2.4.8-p3

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法）>= 2.4.8 &lt; 2.4.9

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

当涉及大量类别和产品时，类别加载会花费较长时间或导致超时问题。

<u>重现步骤</u>：

1. 创建&#x200B;*2500* **[!UICONTROL Categories]**&#x200B;和至少&#x200B;*10000* **[!UICONTROL Products]**：
   1. 创建`setup/performance-toolkit`的副本，并将其放入`./var`以便能够编辑配置文件。
   1. 编辑`small.xml`配置文件，并将&#x200B;**[!UICONTROL Categories]** = *2500*&#x200B;和&#x200B;**[!UICONTROL Products]** = *250000*&#x200B;设置为。
   1. 运行`bin/magento setup:performance:generate-fixtures var/setup/performance-toolkit/profiles/ce/small.xml`。
1. 创建产品和类别后，请确保它们都是锚点，然后运行查询：

   ```
   UPDATE catalog_category_entity_int set value = 1 where attribute_id = (select attribute_id from eav_attribute where attribute_code = 'is_anchor');
   ```

1. 转到管理员菜单，确保您拥有更深入的类别结构，然后将类别2更深入地移动到类别1树中。
1. 重新索引。

<u>预期的结果</u>：

每个类别都从第一次未缓存的尝试中打开，并且只需几秒钟即可完成。

<u>实际结果</u>：

打开类别需要超过一分钟的时间。
