# AC-18128：非英语区域设置的GraphQL订单日期和评论时间戳不正确

AC-18128修补程序修复了GraphQL返回的订单日期和订单注释时间戳在非英语区域设置中显示错误日历日期的问题。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83时，此修补程序可用。 修补程序ID为AC-18128。 请注意，此问题已在Adobe Commerce 2.4.8中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法） 2.4.8

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法）>=2.4.8 &lt;2.4.8-p6

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

GraphQL返回的订单日期和订单评论时间戳在非英语区域设置中显示错误的日历日期。

<u>重现步骤</u>：

1. 在“管理”面板中，转到&#x200B;**[!UICONTROL Stores]** > **[!UICONTROL Configuration]** > **[!UICONTROL General]** > **[!UICONTROL Locale Options]**。 将&#x200B;**[!UICONTROL Timezone]**&#x200B;设置为&#x200B;*欧洲/巴黎*。 将&#x200B;**[!UICONTROL Locale]**&#x200B;设置为&#x200B;*法语（法国）*。 保存配置。
1. 在店面下订单。
1. 执行以下客户订单GraphQL查询：

   ```graphql
   query getOrders {
       customer {
           orders {
               items {
                   orderDateOK: created_at
                   orderDateFAIL: order_date
               }
           }
       }
   }
   ```

<u>预期的结果</u>：

GraphQL响应中的订单日期和评论时间戳反映了正确的日历日期，无论商店区域设置如何。

<u>实际结果</u>：

对于非`en_US`区域设置（如`fr_FR`和`de_DE`），`order_date`显示错误的日历日期，因为存在日期解析问题。
