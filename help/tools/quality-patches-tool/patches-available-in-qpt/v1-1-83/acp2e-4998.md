# ACP2E-4998：缺少SKU导致无法对有效产品进行批量层价格更新

ACP2E-4998修补程序修复了以下问题：当有效负载中不存在一个SKU时，`POST /V1/products/tier-prices` REST API请求完全失败，从而无法更新有效的SKU。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83时，此修补程序可用。 修补程序ID为ACP2E-4998。 请注意，此问题计划在Adobe Commerce 2.4.10中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法） 2.4.7 - p10

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法）>= 2.4.7 &lt; 2.4.8

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

当有效负载中不存在一个SKU时，`POST /V1/products/tier-prices` REST API请求完全失败，导致无法更新有效的SKU。

<u>重现步骤</u>：

1. 识别一个现有的产品SKU（如`product_dynamic_1`）和一个不在目录中的SKU（如`product_dynamic_001`）。
1. 向`/rest/V1/products/tier-prices`提交POST请求，该请求在同一有效负载中包含两个SKU：

   ```json
   {
     "prices": [
       {
         "sku": "product_dynamic_1",
         "customer_group": "General",
         "quantity": 5,
         "price": 31.99,
         "price_type": "fixed",
         "website_id": 0
       },
       {
         "sku": "product_dynamic_001",
         "customer_group": "General",
         "quantity": 5,
         "price": 54.49,
         "price_type": "fixed",
         "website_id": 0
       }
     ]
   }
   ```

<u>预期的结果</u>：

1. 为现有SKU保存了层价格。
1. 响应将缺少SKU报告为项目级错误。

<u>实际结果</u>：

1. 请求失败，错误为&#x200B;*SKU为“%1”的产品不存在。* 用于`product_dynamic_001`。
1. 没有为现有SKU保存层价格。
