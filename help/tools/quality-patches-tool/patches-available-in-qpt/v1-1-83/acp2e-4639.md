# ACP2E-4639：申购单列表项类型在Adobe Commerce GraphQL架构中拼写错误

ACP2E-4639修补程序修复了GraphQL架构中申请列表项类型拼写错误的问题。 新的`requisition_list_items`字段返回拼写正确的`RequisitionListItems`类型，而旧的`items`字段和`RequistionListItems`类型仍然可用，但已弃用。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83时，此修补程序可用。 修补程序ID为ACP2E-4639。 请注意，此问题已在Adobe Commerce B2B 1.5.3中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法）B2B 1.5.2 - p1

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法）B2B >= 1.3.4 &lt; 1.5.3

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=zh-Hans)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

在GraphQL架构中，申请列表项类型拼写错误`RequistionListItems`。 较旧的`items`字段和`RequistionListItems`类型仍然可用，但已弃用。

<u>先决条件</u>：

包含B2B扩展的Adobe Commerce。

<u>重现步骤</u>：

1. 发送以下GraphQL内部检查查询：

   ```
   {
     __type(name: "RequisitionList") {
       fields(includeDeprecated: true) {
         name
         isDeprecated
         type {
           name
         }
       }
     }
   }
   ```

1. 在响应中，检查`items`字段返回的类型。

<u>预期的结果</u>：

1. `requisition_list_items`字段返回拼写正确的`RequisitionListItems`类型。
1. `items`字段和`RequistionListItems`类型仍然可用，并标记为已弃用。

<u>实际结果</u>：

`items`字段返回拼写错误的`RequistionListItems`类型，没有字段返回拼写正确的`RequisitionListItems`类型。
