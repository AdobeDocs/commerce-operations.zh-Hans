# ACP2E-4838：受限管理员用户无法从允许的网站删除客户

ACP2E-4838修补程序修复了具有受限权限的管理员用户无法从客户网格中删除客户的问题。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83时，此修补程序可用。 修补程序ID为ACP2E-4838。 请注意，此问题计划在Adobe Commerce 2.4.10中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法） 2.4.8-p3

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法）>=2.4.4 &lt;2.4.10

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=zh-Hans)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

具有受限权限的Admin用户无法从客户网格中删除客户。

<u>重现步骤</u>：

1. 在“管理”面板中，转到&#x200B;**[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL All Stores]**。 验证&#x200B;**[!UICONTROL Main Website]**&#x200B;是否具有默认&#x200B;**[!UICONTROL Main Website Store]**&#x200B;和&#x200B;**[!UICONTROL Default Store View]**。 创建以下内容：
   * 存储：单击&#x200B;**[!UICONTROL Create Store]**，将&#x200B;**[!UICONTROL Web Site]**&#x200B;设置为&#x200B;**[!UICONTROL Main Website]**，在&#x200B;**[!UICONTROL Name]**&#x200B;中输入`Group A`，输入唯一的&#x200B;**[!UICONTROL Code]**，然后单击&#x200B;**[!UICONTROL Save Store]**。
   * 商店视图：单击&#x200B;**[!UICONTROL Create Store View]**，将&#x200B;**[!UICONTROL Store]**&#x200B;设置为&#x200B;**[!UICONTROL Group A]**，在&#x200B;**[!UICONTROL Name]**&#x200B;中输入`Store View A`，输入唯一的&#x200B;**[!UICONTROL Code]**，将&#x200B;**[!UICONTROL Status]**&#x200B;设置为&#x200B;**[!UICONTROL Enabled]**，然后单击&#x200B;**[!UICONTROL Save Store View]**。
1. 通过&#x200B;**[!UICONTROL Default Store View]**&#x200B;创建客户帐户，使客户属于&#x200B;**[!UICONTROL Main Website]**&#x200B;和&#x200B;**[!UICONTROL Default Store View]**。
1. 转到&#x200B;**[!UICONTROL System]** > **[!UICONTROL Permissions]** > **[!UICONTROL User Roles]**&#x200B;并单击&#x200B;**[!UICONTROL Add New Role]**。
1. 在&#x200B;**[!UICONTROL Role Resources]**&#x200B;中，选择&#x200B;**[!UICONTROL Customers]** > **[!UICONTROL All Customers]**&#x200B;及其&#x200B;**[!UICONTROL Delete]**&#x200B;权限。
1. 在&#x200B;**[!UICONTROL Role Scopes]**&#x200B;中，为&#x200B;**[!UICONTROL Main Website]**&#x200B;选择&#x200B;**[!UICONTROL Custom]**&#x200B;并仅允许`Group A`，将&#x200B;**[!UICONTROL Main Website Store]**&#x200B;保留为未选择。
1. 创建管理员用户并将其分配给受限角色。
1. 以受限用户身份登录到“管理员”面板。
1. 转到&#x200B;**[!UICONTROL Customers]** > **[!UICONTROL All Customers]**。
1. 选择客户并从&#x200B;**[!UICONTROL Actions]**&#x200B;下拉菜单中选择&#x200B;**[!UICONTROL Delete]**。

<u>预期的结果</u>：

受限管理员用户可以打开和删除客户，因为客户的网站在角色范围内，即使客户是在角色范围之外的商店视图中创建的。

<u>实际结果</u>：

客户未被删除，管理员显示以下错误消息： *需要更多权限才能查看此项目。*
