# ACP2E-4973：从店内交付切换到另一种交付方法时不会从购物车中清除商店地址

ACP2E-4973修补程序修复了从&#x200B;**[!UICONTROL In-Store Delivery]**&#x200B;切换到其他传递方法时无法从购物车中清除商店地址的问题。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86时，此修补程序可用。 修补程序ID为ACP2E-4973。 请注意，此问题计划在Adobe Commerce 2.4.10中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法） 2.4.8-p5

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法） 2.4.8-p1 - 2.4.8-p5

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

从&#x200B;**[!UICONTROL In-Store Delivery]**&#x200B;切换到另一个传递方法时不会从购物车中清除商店地址。

<u>先决条件</u>：

Inventory management（多Source Inventory）和店内提货。

<u>重现步骤</u>：

1. 在Admin中，转到&#x200B;**[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Sources]**&#x200B;并单击&#x200B;**[!UICONTROL Add New Source]**。 输入&#x200B;**[!UICONTROL Name]**&#x200B;和&#x200B;**[!UICONTROL Code]**，启用&#x200B;*用作接机地点*，在&#x200B;**[!UICONTROL Contact Info]**&#x200B;下输入&#x200B;**[!UICONTROL Phone]**，在&#x200B;**[!UICONTROL Address Data]**&#x200B;下输入&#x200B;**[!UICONTROL Country]**、**[!UICONTROL State/Province]**、**[!UICONTROL City]**、**[!UICONTROL Street]**&#x200B;和&#x200B;**[!UICONTROL Postcode]**，并保存源。
1. 转到&#x200B;**[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Stocks]**&#x200B;并单击&#x200B;**[!UICONTROL Add New Stock]**。 输入&#x200B;**[!UICONTROL Name]**，在&#x200B;**[!UICONTROL Sales Channels]**&#x200B;下选择网站，在&#x200B;**[!UICONTROL Sources]**&#x200B;下分配新源，并保存库存。
1. 转到&#x200B;**[!UICONTROL Catalog]** > **[!UICONTROL Products]**&#x200B;并创建一个简单的产品。 在&#x200B;**[!UICONTROL Sources]**&#x200B;部分中，单击&#x200B;**[!UICONTROL Assign Sources]**，选择新源，输入正数量，然后保存产品。
1. 转到&#x200B;**[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL Sales]** > **[!UICONTROL Delivery Methods]**，展开&#x200B;**[!UICONTROL In-Store Delivery]**，将&#x200B;**[!UICONTROL Enabled]**&#x200B;设置为&#x200B;*是*，然后单击&#x200B;**[!UICONTROL Save Config]**。
1. 将GraphQL用作注册客户，生成客户令牌(`generateCustomerToken`)，获取购物车ID (`customerCart`)，然后将产品添加到购物车(`addProductsToCart`)。
1. 通过在`pickup_location_code`中仅发送源代码将购物车送货地址设置为取车地点：

   ```
   mutation {
     setShippingAddressesOnCart(input: {
       cart_id: "<cart_id>"
       shipping_addresses: [{ pickup_location_code: "<source_code>" }]
     }) {
       cart { shipping_addresses { pickup_location_code firstname lastname street city postcode } }
     }
   }
   ```

1. 将购物车切换到&#x200B;**[!UICONTROL Flat Rate]**&#x200B;并在响应中选中`shipping_addresses`：

   ```
   mutation {
     setShippingMethodsOnCart(input: {
       cart_id: "<cart_id>"
       shipping_methods: [{ carrier_code: "flatrate", method_code: "flatrate" }]
     }) {
       cart { shipping_addresses { pickup_location_code firstname lastname street city postcode } }
     }
   }
   ```

1. 设置帐单地址(`setBillingAddressOnCart`)和付款方式（`setPaymentMethodOnCart`，例如`checkmo`），然后运行`placeOrder`而不设置新的送货地址。

<u>预期的结果</u>：

1. 在切换到&#x200B;**[!UICONTROL Flat Rate]**&#x200B;后，`pickup_location_code`和取车商店地址将从购物车送货地址中删除。
1. 您必须使用`setShippingAddressesOnCart`设置有效的家庭交货运送地址，才能下订单。

<u>实际结果</u>：

1. 切换到&#x200B;**[!UICONTROL Flat Rate]**&#x200B;后，购物车送货地址仍包含`pickup_location_code`和取货商店地址。
1. 下订单。 在&#x200B;**[!UICONTROL Sales]** > **[!UICONTROL Orders]**&#x200B;中，订单的配送地址是取货商店地址，但交货方式为&#x200B;**[!UICONTROL Flat Rate]**。
