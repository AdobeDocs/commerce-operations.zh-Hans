# ACP2E-5050：在“管理员”中查看或保存RMA时，不会在操作日志报告中显示RMA编号

ACP2E-5050修补程序修复了在管理员中查看或保存RMA时未在&#x200B;**[!UICONTROL Action Logs]**&#x200B;报表中显示RMA编号的问题。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86时，此修补程序可用。 修补程序ID为ACP2E-5050。 请注意，此问题计划在Adobe Commerce 2.4.10中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法） 2.4.8-p5

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法） 2.4.6 - 2.4.9

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

在管理员中查看或保存RMA不会在&#x200B;**[!UICONTROL Action Logs]**&#x200B;报表中显示RMA编号。

<u>重现步骤</u>：

1. 在店面或管理面板中订购简单产品。
1. 在“管理员”面板中，转到&#x200B;**[!UICONTROL Sales]** > **[!UICONTROL Orders]**，打开订单，单击&#x200B;**[!UICONTROL Ship]**，然后单击&#x200B;**[!UICONTROL Submit Shipment]**。
1. 在订单页面上，单击&#x200B;**[!UICONTROL Create Returns]**。 在&#x200B;**[!UICONTROL Return Items]**&#x200B;选项卡上，单击&#x200B;**[!UICONTROL Add Products]**，选择产品，然后单击&#x200B;**[!UICONTROL Add Selected Product(s) to returns]**。
1. 输入&#x200B;**[!UICONTROL Requested]**&#x200B;数量，选择&#x200B;**[!UICONTROL Return Reason]**、**[!UICONTROL Item Condition]**&#x200B;和&#x200B;**[!UICONTROL Resolution]**，然后单击&#x200B;**[!UICONTROL Submit Returns]**。
1. 转到&#x200B;**[!UICONTROL Sales]** > **[!UICONTROL Returns]**&#x200B;并打开新的返回。
1. 转到&#x200B;**[!UICONTROL System]** > **[!UICONTROL Action Logs]** > **[!UICONTROL Report]**，将&#x200B;**[!UICONTROL Action Group]**&#x200B;筛选器设置为&#x200B;*Returns*，单击&#x200B;**[!UICONTROL Search]**，然后检查&#x200B;**[!UICONTROL Details]**&#x200B;列。

<u>预期的结果</u>：

提交返回时记录了&#x200B;*Save*&#x200B;条目，打开时记录的&#x200B;*View*&#x200B;条目在&#x200B;**[!UICONTROL Details]**&#x200B;列中显示了其RMA编号。

<u>实际结果</u>：

这些条目在&#x200B;**[!UICONTROL Details]**&#x200B;列中只显示一个短划线，不显示RMA编号。
