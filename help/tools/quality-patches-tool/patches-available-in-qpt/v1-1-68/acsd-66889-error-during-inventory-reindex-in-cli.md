# ACSD-66889：在CLI中重新索引清单时出错

ACSD-66889修补程序修复了运行清单索引器时发生的错误。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.68时，此修补程序可用。 修补程序ID为ACSD-66889。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法） 2.4.5-p8

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法） 2.4.4 - 2.4.5-p13

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

运行清单索引器时，该进程会引发弃用警告，并且由于字符串语法过时而无法完成。

<u>重现步骤</u>：

1. 使用CLI命令运行清单重新索引：

   ```shell
   php bin/magento indexer:reindex inventory
   ```

<u>预期的结果</u>：

CLI已成功重建清单索引器。

<u>实际结果</u>：

CLI引发已弃用的功能错误，并且清单索引保持为&#x200B;*需要重新索引*&#x200B;状态：

```shell
Deprecated Functionality: Using ${var} in strings is deprecated, use {$var} instead in /home/vendor/magento/module-elasticsearch-catalog-permissions/Model/Adapter/FieldMapper/Product/FieldProvider/FieldName/Resolver/CategoryPermission.php on line 24
```
