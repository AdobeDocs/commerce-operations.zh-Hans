# ACP2E-4194：具有未知筛选器名称的GraphQL请求会导致PHP异常日志

ACP2E-4194修补程序修复了具有未知筛选器名称的GraphQL请求导致PHP异常日志的问题。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82时，此修补程序可用。 修补程序ID为ACP2E-4194。 请注意，此问题计划在Adobe Commerce 2.4.9中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法） 2.4.7-p10、2.4.8-p5

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法） 2.4.7-p10、2.4.8-p5

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=zh-Hans)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

具有未知筛选器名称的GraphQL请求导致PHP异常日志的问题。

<u>重现步骤</u>：

发送筛选器名称未知或不正确的GraphQL请求：

```
query Test($filter: FindFilterType){ cmsBlocks(identifiers:["home"]) { items { title } } }
```

<u>预期的结果</u>：

如果请求无法解析、请求未获得授权或请求存在其他一般问题，则会返回4XX响应代码。 如果可以解析和处理请求，则会返回&#x200B;*200*&#x200B;响应代码。

<u>实际结果</u>：

响应中返回了内部服务器错误，在`exception.log`中出现以下错误：

```
report.CRITICAL: LogicException: Config element "FindFilterType" is not declared in GraphQL schema in /var/lib/internal/Magento/Framework/GraphQl/Config.php:57
```
