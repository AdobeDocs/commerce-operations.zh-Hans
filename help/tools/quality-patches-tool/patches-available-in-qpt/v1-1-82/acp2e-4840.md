# ACP2E-4840： GraphQL产品查询为自定义库存库存上的库存产品返回null数量

ACP2E-4840修补程序修复了以下问题：对于库存中并在自定义库存库存中可供销售的产品，产品GraphQL查询中的quantity字段返回空。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82时，此修补程序可用。 修补程序ID为ACP2E-4840。 请注意，此问题计划在Adobe Commerce 2.4.10中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法） 2.4.8-p4

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法） 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

对于有库存并且可在自定义库存库存中销售的产品，产品GraphQL查询中的“数量”字段会返回null。

<u>先决条件</u>：

已启用MSI。

<u>重现步骤</u>：

1. 创建新源。
1. 在管理员侧边栏上，转到&#x200B;**[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Stock]**。
1. 单击&#x200B;**[!UICONTROL Add New Stock]**。
1. 展开&#x200B;**[!UICONTROL Sales Channels]**&#x200B;并选择股票可用的&#x200B;**[!UICONTROL Websites]**。
1. 展开&#x200B;**[!UICONTROL Sources]**，单击&#x200B;**[!UICONTROL Assign Sources]**，选择要分配的源，然后单击&#x200B;**[!UICONTROL Done]**。
1. 在管理员侧边栏中，转到&#x200B;**[!UICONTROL Catalog]** > **[!UICONTROL Products]**&#x200B;并以编辑模式打开现有产品。
1. 在&#x200B;**[!UICONTROL Sources]**&#x200B;部分中，分配自定义源，将&#x200B;**[!UICONTROL Source Item Status]**&#x200B;设置为&#x200B;**[!UICONTROL In Stock]**，为&#x200B;**[!UICONTROL Qty]**&#x200B;输入非零值，然后保存产品。
1. 在&#x200B;**[!UICONTROL Catalog]** > **[!UICONTROL Products]**&#x200B;中确认产品为分配给自定义库存的网站显示非零&#x200B;**[!UICONTROL Salable Quantity]**。
1. 针对分配给使用自定义库存的网站的商店视图，为该SKU运行以下`products` [!DNL GraphQL]查询：

   ```
   query {
     products(filter: { sku: { in: ["product_dynamic_1"] } }) {
       items {
         sku
         name
         stock_status
         quantity
         max_sale_qty
       }
     }
   }
   ```

1. 观察响应：

   ```
   {
     "data": {
       "products": {
         "items": [
           {
             "sku": "product_dynamic_1",
             "name": "Simple Product 1",
             "stock_status": "IN_STOCK",
             "quantity": null,
             "max_sale_qty": 10000
           }
         ]
       }
     }
   }
   ```

<u>预期的结果</u>：

GraphQL响应会为当前商店/网站上有库存且可销售的产品返回非null数量值。

<u>实际结果</u>：

对于存储使用自定义MSI库存且可在管理员中销售的产品，GraphQL响应返回`quantity = null`，而`stock_status` = `IN_STOCK`。
