# ACP2E-5027：当应用程序锁定使用文件锁定提供程序时，索引器未完成

ACP2E-5027修补程序修复了索引器永远无法完成的问题，因为在启用`use_application_lock`并配置文件锁定提供程序时，索引器会不断尝试获取自己的锁定。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84时，此修补程序可用。 修补程序ID为ACP2E-5027。 此问题计划在Adobe Commerce 2.4.10中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法） 2.4.9

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法） 2.4.4 - 2.4.9

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

索引器从不结束，因为在启用`use_application_lock`且配置了文件锁定提供程序时，它们一直尝试获取自己的锁定。

<u>重现步骤</u>：

1. 在`app/etc/env.php`中，启用索引器的应用程序锁定，并将锁定提供程序设置为文件：

   ```
   'indexer' =>
   array (
     'use_application_lock' => true,
   ),
   'lock' =>
   array (
     'provider' => 'file',
     'config' =>
     array (
       'path' => '<magento_root>/var/lock',
     ),
   )
   ```

1. 运行`catalog_product_category`索引器：

   ```
   bin/magento indexer:reindex catalog_product_category
   ```

<u>预期的结果</u>：

`catalog_product_category`重新索引成功完成。

<u>实际结果</u>：

重新索引从不会完成。
