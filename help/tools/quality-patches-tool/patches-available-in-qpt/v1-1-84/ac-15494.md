# AC-15494：GraphQL产品查询返回HTML转义的产品名称

AC-15494修补程序修复了`products`查询返回带有HTML转义特殊字符而不是其原始字符的产品名称的问题。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84时，此修补程序可用。 修补程序ID为AC-15494。 请注意，此问题计划在Adobe Commerce 2.4.9中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法） 2.4.8-p5

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法） 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

`products`查询返回的产品名称带有HTML转义的特殊字符，而不是其原始字符。

<u>重现步骤</u>：

1. 创建名为`55" 4K UHD Smart TV`且具有SKU `testsku`的新产品。
1. 提交以下GraphQL查询：

   ```
   query {
       products(search: "testsku" ) {
           items {
               sku
               name
               description {
                   html
               }
               short_description {
                   html
               }
   
               price_range {
                   maximum_price {
                       final_price {
                           value
                           currency
                       }
                       regular_price {
                           value
                           currency
                       }
                   }
               }
           }
       }
   }
   ```

<u>预期的结果</u>：

`products`查询返回保存的产品名称及其原始双引号。

<u>实际结果</u>：

返回的产品名称包含HTML转义的双引号，而不是原始字符。
