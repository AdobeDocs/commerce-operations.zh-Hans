# ACP2E-5263：产品CSV导出提前停止并省略产品

ACP2E-5263修补程序修复了CSV产品导出在包含所有产品之前可能会停止的问题，这会生成不完整的文件。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84时，此修补程序可用。 修补程序ID为ACP2E-5263。 请注意，此问题计划在Adobe Commerce 2.4.10中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法） 2.4.8-p5

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法） 2.4.5 - 2.4.8-p5

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

在包含所有产品之前，可以停止将产品导出到CSV，这会生成一个不完整的文件。

<u>重现步骤</u>：

1. 确保目录包含多个产品和一个辅助存储视图。
2. 使用测试产品，其中为次商店视图设置了图像标签，但在默认商店视图中没有相应的产品图像可用。
3. 在Admin中，转到&#x200B;**[!UICONTROL System]** > **[!UICONTROL Data Transfer]** > **[!UICONTROL Export]**。
4. 将&#x200B;**[!UICONTROL Entity Type]**&#x200B;设置为&#x200B;**[!UICONTROL Products]**&#x200B;并将&#x200B;**[!UICONTROL Export File Format]**&#x200B;保留设置为&#x200B;**[!UICONTROL CSV]**。
5. 将导出筛选器保留为空，并且不排除属性。
6. 向下滚动并单击&#x200B;**[!UICONTROL Continue]**。
7. 等待异步导出完成，然后下载并打开CSV文件。

<u>预期的结果</u>：

导出完成并生成一个包含每个产品的CSV。

<u>实际结果</u>：

导出过程将中止，但管理员指示导出文件已准备就绪，并且提供的CSV缺少某些产品。
