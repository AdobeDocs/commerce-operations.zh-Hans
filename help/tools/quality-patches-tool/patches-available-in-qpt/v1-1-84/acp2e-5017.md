# ACP2E-5017：对于没有公司的客户，GraphQL客户角色查询失败

ACP2E-5017修补程序修复了GraphQL `customer`查询的`role`字段为未分配给公司的客户返回&#x200B;*内部服务器错误*&#x200B;的问题。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84时，此修补程序可用。 修补程序ID为ACP2E-5017。 请注意，此问题计划在Adobe Commerce B2B 1.5.4中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法）B2B 1.5.3

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法）B2B 1.5.0 - 1.5.3

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

GraphQL `customer`查询的`role`字段为未分配给公司的客户返回&#x200B;*内部服务器错误*。

<u>先决条件</u>：

已安装B2B。

<u>重现步骤</u>：

1. 在Admin中，转到&#x200B;**[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL General]** > **[!UICONTROL B2B Features]**，将&#x200B;**[!UICONTROL Enable Company]**&#x200B;设置为&#x200B;*[!UICONTROL Yes]*，然后单击&#x200B;**[!UICONTROL Save Config]**。
1. 创建未分配给公司的客户帐户。
1. 使用有效的客户令牌发送以下GraphQL查询：

```
   query {
     customer {
       email
       firstname
       role {
         id
         name
       }
     }
   }
```

<u>预期的结果</u>：

查询返回`role`设置为&#x200B;*null*&#x200B;的客户数据，没有错误。

<u>实际结果</u>：

查询返回&#x200B;*内部服务器错误*。
