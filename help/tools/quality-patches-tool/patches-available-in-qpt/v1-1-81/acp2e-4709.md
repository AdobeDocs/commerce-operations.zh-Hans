# ACP2E-4709：当页面层次结构包含双引号时，CMS页面不会保存在页面生成器中

ACP2E-4709修补程序修复了当页面层次结构包含双引号时，CMS页面无法在页面生成器中保存的问题。 安装[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.81时，此修补程序可用。 修补程序ID为ACP2E-4709。 请注意，此问题计划在Adobe Commerce 2.4.9中修复。

## 受影响的产品和版本

**为Adobe Commerce版本创建了修补程序：**

* Adobe Commerce（所有部署方法） 2.4.7-p9

**与Adobe Commerce版本兼容：**

* Adobe Commerce（所有部署方法） 2.4.7 - 2.4.8-p5

>[!NOTE]
>
>该修补程序可能适用于具有新[!DNL Quality Patches Tool]发行版本的其他版本。 要检查修补程序是否与您的Adobe Commerce版本兼容，请将`magento/quality-patches`包更新到最新版本，并在[[!DNL Quality Patches Tool]：搜索修补程序页面](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)上检查兼容性。 使用修补程序ID作为搜索关键字来查找修补程序。

## 问题

当页面层次结构包含双引号时，CMS页面无法在页面生成器中保存。

<u>先决条件</u>：

已启用页面生成器。

<u>重现步骤</u>：

1. 在管理员侧边栏中，转到&#x200B;**[!UICONTROL Stores]** > **设置** > **配置**。 在左侧面板中的&#x200B;**[!UICONTROL General]**&#x200B;下，选择&#x200B;**内容管理**。
1. 展开&#x200B;**[!UICONTROL CMS Page Hierarchy]**，将&#x200B;**[!UICONTROL Enable Hierarchy Functionality]**&#x200B;设置为&#x200B;**[!UICONTROL Yes]**，然后单击&#x200B;**[!UICONTROL Save Config]**。
1. 在管理员侧边栏中，转到&#x200B;**内容** > **[!UICONTROL Elements]** > **[!UICONTROL Pages]**&#x200B;并单击&#x200B;**[!UICONTROL Add New Page]**。
1. 输入包含双引号的页面标题，将该页面放在&#x200B;**层次结构**&#x200B;选项卡的网站根目录下，然后单击&#x200B;**[!UICONTROL Save]**。
1. 使用页面生成器将内容添加到页面，然后单击&#x200B;**[!UICONTROL Save]**。

<u>预期的结果</u>：

新的CMS页面保存成功，并且没有错误。

<u>实际结果</u>：

- 新的CMS页面不会保存。
- 浏览器控制台显示以下错误： `Uncaught SyntaxError: JSON.parse: expected ',' or '}' after property value in object at line 1 column 79 of the JSON data`。
